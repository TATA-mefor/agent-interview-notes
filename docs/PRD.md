# Todo-List 功能产品需求文档（PRD）

## 一、目标

把 `/todos` 页面改造成「卡片学习队列」：

- 按 **预习 / 学习 / 复习** 三列组织题库中的卡片
- 每列显示当前阶段的卡片清单和数量
- 点击「开始学习 / 开始复习」按顺序进入卡片学习流程
- 完成一张卡片后自动进入下一张
- 复习完成后由系统现有复习算法自动调度下一次复习时间

整体体验参考「不背单词」的学习队列。

---

## 二、给谁用

正在准备 Agent/LLM 面试的学习者。他们已经导入了题库卡片，希望有一个按学习阶段组织的「今日该学什么」入口，而不是手动去复习中心选题。

---

## 三、核心功能

### 1. 自动分阶段

系统根据卡片已有数据自动把卡片分到三列：

| 阶段 | 规则 | 说明 |
|---|---|---|
| 预习 | `review_count = 0` | 从未学习过的新卡片 |
| 学习 | `review_count > 0` 且 `next_review_date > 今天` | 预习后自动进入学习，还没到复习日期 |
| 复习 | `next_review_date <= 今天` | 今天需要复习的卡片 |

每天打开页面时自动重新计算。

### 2. 每日预习题量设置

- 用户可在设置页配置「每日预习题量」，范围 10–20 题，默认 10 题
- 设置保存到 `app_settings` 表，刷新后仍保留
- 预习列显示「今日可预习 X 题」，点击「开始预习」即按该数量启动学习会话
- 已完成预习的卡片自动进入学习列表

### 3. 三列看板

- 固定三列：预习 / 学习 / 复习
- 每列顶部显示本阶段卡片数量
- 列内显示卡片标题列表（可滚动）
- 每列有一个主按钮：
  - 预习列：「开始预习」
  - 学习列：「继续学习」
  - 复习列：「开始复习」
- 空列显示提示：「本阶段暂无卡片」

### 4. 卡片学习会话

- 点击按钮后进入全屏学习会话（例如 `/todos/study?phase=review`）
- 一次只展示一张卡片
- 卡片正面显示题目，点击/按键后翻面显示答案
- 翻面后提供评级按钮：重来 / 困难 / 良好 / 简单
- 评级后调用复习算法，然后自动加载下一张卡片
- 支持快捷键：空格/回车翻面，1/2/3/4 评级

### 5. 与复习算法联动

- 评级完成后，后端调用现有 `reviewService.completeReview` 逻辑
- 更新卡片掌握度、复习次数、last_review、next_review_date、review_priority
- 写入 review_log
- 如果当前卡片进入下一阶段，它会在会话结束后从当前列移除

### 6. 会话结束

- 当前列所有卡片处理完后显示完成页
- 显示本次会话复习了 X 张卡片
- 提供「返回待办」和「再学一轮」按钮

---

## 四、明确不做

- 独立的文本待办项（本次全部基于现有卡片）
- 手动把卡片加入/移出待办队列
- 自定义阶段名称或新增阶段
- 截止日期待办提醒
- 拖拽排序 / 手动排序
- 子任务 / 标签 / 优先级字段
- 多人协作 / 权限管理
- 通知、邮件、推送

---

## 五、怎样算做成了（验收标准）

1. 用户在侧边栏、底部 tab、首页模块区能看到「待办」入口
2. `/todos` 页面展示预习 / 学习 / 复习 三列
3. 每列显示对应阶段的卡片数量和卡片标题
4. 空列显示「本阶段暂无卡片」
5. 可在设置页修改「每日预习题量」（10–20 题），刷新后保留
6. 点击「开始预习/学习/复习」进入学习会话
7. 学习会话中完成一张卡片后自动进入下一张
8. 评级后卡片掌握度、复习次数、下次复习日期被正确更新
9. 会话结束后返回 `/todos`，列数据已刷新
10. `npm run typecheck` 通过

## 六、实施切片

切片从第一个用户可见的可用功能开始编号，数据库/路由骨架等准备工作不计入切片。

### 切片 1：三列看板显示卡片清单 + 每日预习题量设置

**完成后能看到的效果**
- `/todos` 页面出现预习 / 学习 / 复习 三列
- 每列显示属于该阶段的卡片标题
- 每列顶部显示卡片数量
- 每列有「开始」按钮（预习/学习/复习文案不同）
- 预习列显示「今日可预习 X 题」
- 设置页新增「待办设置」，可修改每日预习题量（10–任意 题）
- 空列显示友好提示

**验收**
- 分阶段规则正确（可用测试数据验证：新卡进预习，学过未到期进学习，到期进复习）
- 每日预习题量保存后刷新仍保留
- 卡片标题可点击或按钮可进入会话
- typecheck 通过

---

### 切片 2：卡片学习会话（翻页 + 评级）

**完成后能看到的效果**
- 点击「开始」按钮进入 `/todos/study?phase=xxx` 全屏会话
- 按顺序显示当前阶段的卡片
- 点击卡片翻面显示答案
- 显示重来 / 困难 / 良好 / 简单 四个评级按钮
- 评级后自动加载下一张

**验收**
- 会话只加载对应阶段的卡片
- 翻面、评级、下一张流程顺畅
- 最后一张完成后显示完成页

---

### 切片 3：评级后调用复习算法

**完成后能看到的效果**
- 评级不再只是简单改掌握度，而是调用后端复习服务
- 后端更新 mastery、review_count、last_review、next_review_date、review_priority
- 写入 review_log
- 会话结束后 `/todos` 看板数据刷新，已复习卡片离开当前列

**验收**
- 评级前后卡片 `next_review_date` 变化
- `review_log` 新增记录
- 返回看板后数量正确

- 完成当前列所有卡片后显示「本轮完成」页面
- 显示本次复习张数
- 提供「返回待办」和「再学一轮」按钮
